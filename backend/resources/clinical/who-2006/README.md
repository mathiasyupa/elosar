# OMS 2006 — tablas LMS 0–5 años

Copias sin modificar de las **expanded tables** publicadas por la OMS para
construir curvas nacionales: peso para la edad, longitud/estatura para la edad
y perímetro cefálico para la edad, por sexo. Cada hoja contiene edad exacta en
días (0–1856), LMS y límites de DE.

Fuente: <https://www.who.int/tools/child-growth-standards/standards>

La aplicación calcula en servidor y persiste el SHA-256 de cada tabla en el
snapshot clínico. No sustituir estas tablas sin una nueva versión de estándar,
pruebas de referencia y revisión pediátrica.
